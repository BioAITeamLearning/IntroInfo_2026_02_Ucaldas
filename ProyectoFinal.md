# Proyecto final · Mi agente (Ejercicio 3) 🚀

## La consigna

Es el **Ejercicio 3** del curso (35% de la nota), sustentado en el Demo Day.

Elige **un problema real de tu carrera, trabajo, colectivo o vida** y resuélvelo combinando lo que construiste en el curso. Se presenta en el {doc}`S16_DemoDay` con una demo en vivo de 5 minutos y se publica en tu página web.

**Requisito mínimo:** integrar al menos **tres** de estas piezas, de al menos **dos** unidades distintas:

| Pieza | Sesión |
|---|---|
| Cuaderno de NotebookLM con fuentes reales | S2–S3 |
| Agente v0.1 (Gem / Proyecto) con instrucciones propias | S4 |
| Informe investigado y verificado | S5 |
| Página web / portafolio | S7 |
| Contenido multimedia (infografía, presentación, video) | S8 |
| Sistema de gestión (AppSheet) + automatización | S9 |
| Dataset limpio + análisis + dashboard | S10–S12 |
| Modelo entrenado (Teachable Machine) o app en AI Studio | S13 |
| Agente sobre carpeta (Gemini CLI / Claude Code) o Opal | S14 |
| Bot de Telegram / flujo automatizado | S15 |

## Ejemplos por carrera (para inspirar, no para copiar)

| Carrera | Proyecto | Piezas |
|---|---|---|
| **Biología** | *Bitácora de campo inteligente*: app para registrar muestras con foto y GPS → dashboard de especies por sitio → bot que responde preguntas sobre los protocolos del laboratorio | AppSheet · Looker · Telegram + PDFs |
| **Derecho** | *Consultorio jurídico asistido*: página del consultorio → sistema de casos con recordatorio de términos → agente que redacta borradores de derechos de petición desde una carpeta de casos | Sites · AppSheet + Apps Script · Gemini CLI |
| **Artes** | *Catálogo vivo de un colectivo*: web con catálogo de obras → fichas técnicas y textos curatoriales generados desde la carpeta de imágenes → video promocional → flujo que publica en redes | Lovable · Gemini CLI · Veo/CapCut · n8n |
| **Deporte** | *Monitor de carga de entrenamiento*: formulario diario de RPE → dashboard de carga semanal → alerta automática al entrenador → modelo que reconoce la postura de un ejercicio | Forms/Sheets · Looker · n8n · Teachable Machine |
| **Cualquiera** | *Mi tutor personal*: cuaderno con todo el semestre → Gem con reglas de estudio → bot de Telegram para repasar → guía de estudio y podcasts automáticos cada semana | NotebookLM · Gems · n8n |

## Entregables

1. **Demo en vivo** (5 min) en el Demo Day + video de respaldo de 1 min.
2. **Página del proyecto** en tu web con: problema, usuario, piezas usadas, enlaces a todo funcionando, **declaración de uso de IA** (qué herramienta, para qué, qué verificaste), limitaciones y próximos pasos.
3. Se califica con la rúbrica de {doc}`Metodologia`: funciona · aplicado a tu carrera · sustentación · publicado y declarado.
