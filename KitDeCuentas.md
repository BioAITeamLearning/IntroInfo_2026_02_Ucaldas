## Ruta pro (opcional): la terminal 🧗

Para correr agentes en tu computador (Sesiones 11 y 14) necesitas:

1. **Node.js** (versión LTS): [nodejs.org](https://nodejs.org)
2. **Gemini CLI** (gratis con tu cuenta Google):

```bash
npm install -g @google/gemini-cli
```

3. O **Claude Code** (requiere plan de Claude o API key):

```bash
npm install -g @anthropic-ai/claude-code
```

```{admonition} Seguridad 🔐
:class: warning
Activa la **verificación en dos pasos** en tu cuenta Google y usa un gestor de contraseñas ([Bitwarden](https://bitwarden.com) es gratis). Lo hacemos juntos en la Sesión 3. **Nunca** pegues contraseñas, números de tarjeta o datos de pacientes/clientes en un chat de IA.
```
