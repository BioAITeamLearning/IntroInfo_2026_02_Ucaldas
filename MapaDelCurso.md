## Hilos que atraviesan todo el curso

Estas tres capacidades **no** se quedan para la última unidad; aparecen desde el inicio y suben de nivel cada vez:

| Hilo | Nivel 1 | Nivel 2 | Nivel 3 | Nivel pro |
|---|---|---|---|---|
| 📂 **Analizar carpetas de documentos** | S2: NotebookLM con tus fuentes | S4: un Gem que lee tu hoja de cálculo y tus formatos | S7: correos, chats, fotos y audios de un negocio | S17: agente que lee, clasifica y renombra tu carpeta |
| 🤖 **Crear y correr agentes** | S3: un Gem con tu ficha de instrucciones | S4: Gems con documentos y herramienta fija | S10: vibe coding (la IA programa por ti) | S17: Gemini CLI / Claude Code + Opal |
| ⚙️ **Automatizar** | S12: Apps Script que envía correos solos | S13: fórmulas `=AI()` en Sheets | S15: dashboard que se actualiza solo | S18: bot de Telegram que responde con tus PDFs |

```{admonition} Ruta pro 🧗
:class: tip
En varias sesiones hay una caja **"Ruta pro"** para quien quiera ir más allá (normalmente: usar la terminal). No es obligatoria, pero suma para el proyecto final.
```

```{warning}
Las herramientas de IA cambian cada mes. Los nombres, límites gratuitos y funciones descritas aquí se verifican antes de cada sesión; si algo cambió, en clase usamos la alternativa equivalente.
```
